LIHAON PDF 앱 개인정보처리방침

최초 시행일: 2026-08-20 · 개정일: 2026-09-25 · 주식회사 리하온 (이하 "회사")

본 방침은 회사가 배포하는 모바일 PDF 뷰어 앱 「LIHAON PDF – 심플 PDF 리더」(이하 "앱")에 적용됩니다. iOS·Android 버전에 공통 적용됩니다.

1. 회사 서버로 정보를 수집하지 않습니다

앱에는 회원가입, 로그인, 광고, 분석·추적 SDK가 없습니다. 회사는 앱을 통해 사용자의 문서, 최근 파일 목록 또는 이용 기록을 회사 서버로 수집하지 않습니다. 열람과 검색은 앱에 포함된 PDF 처리 기능으로 기기에서 수행합니다.

2. 문서 처리

앱은 사용자가 선택한 PDF를 기기에서 처리하며 회사 서버로 업로드하지 않습니다. 사용자가 운영체제의 파일 선택기에서 클라우드 저장소의 문서를 선택하거나 인쇄를 요청하면, 해당 파일 제공자·운영체제·인쇄 서비스가 작업에 필요한 문서를 처리할 수 있고 네트워크가 사용될 수 있습니다. 이러한 사용자가 요청한 기능에는 해당 서비스의 정책이 적용됩니다.

3. 기기 내 저장 정보

Android는 최근 파일 이름과 위치 참조, 다시 열기에 필요한 운영체제의 파일 접근 권한을 기기에 저장합니다. iOS는 다시 열기와 인쇄를 위해 앱의 내부 저장 공간에 문서 사본을 보관합니다. 최근 목록에는 최대 8개를 표시하지만, iOS의 이전 보관 사본은 기록을 지울 때까지 남을 수 있습니다.

개선된 출시 빌드의 [최근 기록 지우기]는 Android의 최근 목록·지속 접근 권한과 iOS의 앱 내 문서 사본을 삭제합니다. 사용자가 선택한 원본 파일은 삭제하지 않습니다. 운영체제에서 앱 데이터를 삭제하거나 앱을 완전히 삭제하여 앱 내 자료를 지울 수도 있습니다. iOS의 앱 정리하기(Offload)는 앱 데이터 삭제와 다릅니다.

개선된 출시 빌드는 최근 기록과 보관 사본을 운영체제의 앱 백업 대상에서 제외하도록 설정합니다. 이전 테스트 빌드에서 생성된 백업, 파일 제공자가 보관하는 원본, 사용자가 별도로 만든 사본은 앱에서 삭제하지 않습니다. 기존 백업은 사용 중인 운영체제·백업 서비스에서 관리할 수 있습니다.

4. 앱 권한

앱은 위치, 카메라, 연락처 접근이나 광고 식별자를 요구하지 않습니다. Android 앱은 INTERNET 권한을 선언하지 않습니다. 문서 열기는 운영체제의 표준 파일 선택기 또는 다른 앱의 "LIHAON PDF로 열기"를 통해 사용자가 선택한 문서에 접근합니다. 인쇄는 운영체제의 인쇄 기능을 이용합니다.

5. 제3자 제공

회사가 앱에서 수집한 문서·이용 기록을 제3자에게 판매하거나 제공하는 기능은 없습니다. 사용자가 직접 요청하는 클라우드 파일 열기·인쇄 등의 처리는 위 2항과 같습니다.
