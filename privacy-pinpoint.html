시행일: 2026년 11월 5일 · 주식회사 리하온

기기 안에서 검색합니다

핀포인트는 사용자가 연결한 폴더의 파일 이름·위치·종류·크기·수정일, 즐겨찾기와 앱 설정을 기기에만 저장합니다. 파일 내용을 색인하지 않으며 회사 서버나 분석 서비스로 전송하지 않습니다. 로그인, 광고, 구독, 분석·추적 SDK가 없습니다.

접근할 위치를 직접 선택합니다

iPhone/iPad에서는 Files 선택기로 연결한 폴더에만 접근합니다. Android에서는 사용자가 고른 폴더에 접근하며, 사용자가 별도로 허용한 경우 공용 저장소 파일 이름을 검색합니다. 다른 앱의 비공개 저장소에 접근하지 않습니다. 파일 제공자가 지원하는 범위와 운영체제 권한이 적용됩니다.

열기와 공유

사용자가 선택한 파일의 미리보기·열기·공유는 운영체제와 사용자가 선택한 앱이 처리합니다. 클라우드 파일을 열면 파일 제공자가 다운로드할 수 있습니다. 공유 대상에 전달되는 파일에는 해당 대상의 정책이 적용됩니다. 색인 작업에서는 파일 내용을 읽거나 업로드하지 않습니다. 원본 파일의 이동·수정·삭제 기능은 제공하지 않습니다.

기록과 삭제

최근 검색어는 최대 8개를 이 기기에 저장하며 설정에서 끄거나 지울 수 있습니다. 기록을 끄면 현재 검색어도 다음 실행을 위한 저장에서 제외됩니다. 위치 연결을 해제하면 해당 위치의 검색 목록과 접근 연결을 지웁니다. 앱을 삭제하면 앱이 보관한 설정과 검색 목록도 운영체제에서 삭제됩니다. 원본 파일이나 다른 앱·클라우드의 사본은 삭제하지 않습니다.

운영체제의 기기 백업·기기 이전 설정에 따라 일부 앱 설정과 검색 기록이 백업되거나 복원될 수 있습니다. 회사는 운영체제 백업에 접근하지 않습니다. iOS 검색 색인 데이터베이스는 백업 제외 대상으로 설정하며 Android 앱 백업은 사용하지 않습니다.

지원 문의

사용자가 이메일로 문의하면 발신 주소와 직접 작성한 내용이 지원 담당자에게 전달되어 답변에 사용됩니다. 파일 이름·문서·스크린샷·기기 정보는 앱에서 자동 첨부하지 않습니다. 민감정보나 비밀번호를 보내지 마세요. 문의 삭제 요청은 같은 연락처로 해 주세요.
